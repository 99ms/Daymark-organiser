# Security Policy

## Reporting Security Vulnerabilities

If you discover a potential security issue in Daymark Organiser, please report it responsibly.

Do **not** create a public GitHub Issue for security vulnerabilities.

Instead, please use GitHub's **Private Security Advisory** feature on the repository if available, or contact the maintainer directly.

When reporting an issue, please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Impact assessment.

Thank you for helping keep Daymark Organiser secure!
