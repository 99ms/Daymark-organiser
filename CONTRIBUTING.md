# Contributing to Daymark Organiser

Thank you for your interest in contributing to Daymark Organiser!

## Development Setup

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/99ms/Daymark-organiser.git
   cd Daymark-organiser
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```

## Workflow & Guidelines

- **Branching**: Create a focused branch for your change (e.g. `feature/my-feature` or `fix/my-fix`).
- **Code Style**: Maintain existing TypeScript conventions, minimal dependencies, and clean code formatting.
- **Design Philosophy**: Keep the UI minimal, fast, desktop-friendly, and scannable. Avoid adding clutter or excessive visual elements.
- **Verification**: Run `npm run build` locally before opening a pull request to ensure zero TypeScript or build errors.

## Opening a Pull Request

Provide a clear summary of your changes, what problem they solve, and steps taken to test them.
